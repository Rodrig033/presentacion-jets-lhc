Discusión

No era la red: era la información

Grosor de flecha = % de la clase real mal clasificada (modelo final, prueba). Interpretación: hipótesis compatible con los datos.

① Techo de información

×120 parámetros, más regularización o más épocas: todo converge a ≈0.776. Con estos 16 observables, las clases se traslapan.

② Los bosones pierden estructura

2 núcleos → 1 es frecuente (W, Z → q ~15 %); 1 → 2 es raro (2–5 %). Si se pierde un núcleo, queda un «jet de quark». Excepción: gluon ↔ top ~7 % en ambos sentidos.

③ Estable, pero con límites

±0.0002 entre semillas. Limitaciones: datos simulados, una sola partición, SiLU es más costosa que ReLU en FPGA.

Conclusión

Una red pequeña ya llega al límite de estos 16 números

+0.41 puntos de F1-macro sobre la red del CERN, estable en 3 semillas y en las 5 clases.

Protocolo reproducible: partición fija, decisiones solo con validación, prueba abierta una vez, 42 corridas.

Hallazgo: el cuello de botella es la información de entrada, no el tamaño de la red.

Partición estratificada 70/15/15 y reproducible

def make_split(y, seed=42, val=0.15, test=0.15):
    """Partición estratificada 70/15/15. Devuelve índices (no datos)."""
    idx = np.arange(len(y))
    idx_train, idx_tmp = train_test_split(
        idx, test_size=val + test, stratify=y, random_state=seed)
    # Del 30 % restante, la mitad es validación y la mitad prueba.
    idx_val, idx_test = train_test_split(
        idx_tmp, test_size=test / (val + test), stratify=y[idx_tmp], random_state=seed)
    return np.sort(idx_train), np.sort(idx_val), np.sort(idx_test)

Preprocesamiento sin fuga de información

def prepare(split_seed=42, include_test=False,
            transform="standard", drop_features=()):
    df = load_dataframe()
    if drop_features:                       # final: quita d2_a1_b1_mmdt (duplicada)
        df = df.drop(columns=list(drop_features))
    X, y, feature_names, class_names = encode(df)
    tr, va, te = get_split(y, seed=split_seed)
    scaler = (YeoJohnson() if transform == "yeojohnson" else Standardizer()).fit(X[tr])
    #                                       se ajusta SOLO con entrenamiento ^^^^^
    out = {"X_train": scaler.transform(X[tr]), "y_train": y[tr],
           "X_val":   scaler.transform(X[va]), "y_val":   y[va], ...}
    if include_test:                         # solo evaluate_test.py --congelado
        out["X_test"] = scaler.transform(X[te]); out["y_test"] = y[te]
    return out

Si el escalado usara todo el dataset, la media y la desviación «verían» la prueba: eso es fuga de información.

Ciclo de entrenamiento

g = torch.Generator(device="cpu").manual_seed(seed)   # orden de minilotes reproducible
for epoch in range(1, cfg["epochs"] + 1):
    model.train()
    perm = torch.randperm(len(Xtr), generator=g).to(device)
    for i in range(0, len(Xtr), bs):
        b = perm[i:i + bs]
        opt.zero_grad(set_to_none=True)
        loss = loss_fn(model(Xtr[b]), ytr[b])            # CrossEntropyLoss sobre logits
        loss.backward(); opt.step()
    pred = predict(model, Xva)
    val_f1 = f1_score(y_val_np, pred, average="macro")  # sklearn.metrics.f1_score
    if sched_mode == "epoch": sched.step()              # coseno en el modelo final
    if val_f1 > best_f1:                                # checkpoint de la mejor época
        best_f1, best_epoch, wait = val_f1, epoch, 0
        torch.save({...}, out / "best.pt")
    else:
        wait += 1
        if wait >= patience: break                   # early stopping
